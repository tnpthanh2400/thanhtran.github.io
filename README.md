# Thanh Tran — B2B Growth Portfolio

Static multi-page portfolio built for GitHub Pages. No Wix, Squarespace, Webflow, or paid hosting is required.

## Pages
- `index.html` — homepage, impact metrics, featured work
- `work.html` — filterable project / case-study index
- `case-revenue-engine.html` — Demandbase + Salesforce + Sales activation case study
- `case-reactivation.html` — dormant / lost account reactivation growth case study
- `case-demand-gen.html` — integrated demand generation case study
- `approach.html` — interactive funnel diagnostic + 8-step growth method
- `about.html` — capabilities, tools, contact
- `404.html` — custom error page

## Before publishing
Open `about.html` and replace:
- `YOUR_EMAIL_HERE`
- `YOUR_LINKEDIN_URL_HERE`

## GitHub Pages deployment
1. Upload every file and the entire `assets` folder to the root of your `tnpthanh2400.github.io` repository.
2. In GitHub, open **Settings → Pages**.
3. Source: **Deploy from a branch**.
4. Branch: **main** / folder: **/(root)**.
5. Save.

Your site should publish at `https://tnpthanh2400.github.io/`.

## Visual direction
Dark navy + electric blue + teal. Vanilla HTML/CSS/JS only, so it is fast, portable, and easy to host free on GitHub Pages.
